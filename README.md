# Ankit Sharma — Portfolio

A responsive cinematic portfolio built with plain HTML, CSS and JavaScript. The hero scrubs a 238-frame portrait sequence against scroll position, with layered CSS 3D orbits, pointer-driven camera parallax and interactive scene markers. Perspective hover cards, animated impact metrics and scroll reveals carry the motion language through the résumé. Animations honor reduced-motion preferences.

## Run locally

From this directory, start any static HTTP server, for example:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.
